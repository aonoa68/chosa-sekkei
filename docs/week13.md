# 第13回　検査と実験

観測・実験・社会調査の違いを整理し、実験による因果関係の検出（バンデューラの実験、変数の統制）と、調査で用いる統計的な統制を説明します。検査については妥当性と信頼性、ノルムと標準得点、古典的テスト理論、項目反応理論を扱います。
