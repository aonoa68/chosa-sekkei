# 第2回　全数調査と標本調査

全数調査と標本調査の違い、標本誤差と非標本誤差を説明します。全数調査の例として日本の国勢調査（歴史・調査項目・調査票）を、標本調査の例として1948年の「日本人の読み書き能力調査」とその得点分布の解釈をめぐる議論を取り上げます。
