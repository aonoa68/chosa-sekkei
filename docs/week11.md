# 第11回　量的調査の集計分析1：母数の推定

記述統計と推測統計の違い、大数の法則と中心極限定理、正規分布を確認したうえで、点推定と区間推定（母平均・母比率の信頼区間）を説明します。後半は検定の考え方（2種類の過誤、有意水準、検出力、Z検定、p値）を扱います。
