## この授業について

社会調査を実施するための技法を、調査の企画・設計からデータの収集と整理までの流れに沿って学ぶ授業です。統計的な社会調査を中心に、標本抽出、調査票の作成、実査の方法、データの作成、集計分析の考え方を扱い、質的調査や検査・実験的手法にも部分的に触れます。社会調査士資格のB科目に対応しています。
